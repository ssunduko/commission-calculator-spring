WebMCP — Imperative Tool Registration

This page implements the WebMCP specification, registering commission AI tools via the imperative navigator.modelContext.registerTool() API. AI agents can discover and invoke these tools directly from the browser context.

WebMCP treats this web page as an MCP server — tools execute client-side JavaScript that calls the backend REST API, enabling collaborative agent-user workflows.

WebMCP Specification Reference

Imperative API

navigator.modelContext.registerTool({
  name: "askCommissionQuestion",
  description: "RAG-powered Q&A about commissions",
  inputSchema: {
    type: "object",
    properties: {
      question: { type: "string" }
    },
    required: ["question"]
  },
  execute: async (input, client) => {
    const res = await fetch("/api/ai/rag/ask", {
      method: "POST",
      headers: {"Content-Type": "application/json"},
      body: JSON.stringify(input)
    });
    return await res.json();
  },
  annotations: { readOnlyHint: true }
});

Key Concepts

1 registerTool() — Registers a tool with name, schema, and execute callback
2 inputSchema — JSON Schema describing the tool's parameters
3 execute callback — Async function invoked when an agent calls the tool
4 AbortSignal — Unregisters tools via AbortController.abort()
5 readOnlyHint — Annotation indicating the tool only reads data
